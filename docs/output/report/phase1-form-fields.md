## 作品方向（可直接粘贴）

操作系统智能创新。作品 LUT-SA 面向端侧低比特大模型推理，将比特级查找表（LUT）加速内核封装为 OpenHarmony / HarmonyOS 用户态 SystemAbility，并结合轻量行为与负载感知做动态资源调度，在现有操作系统架构下提升系统 AI 任务运行效率，不修改 OS 内核。

（字数约 120）

## 作品简介（可直接粘贴）

边缘设备部署低比特大模型时，主流反量化路径带来访存与转换开销，首字延迟与能耗在多任务下进一步恶化；纯应用层 Demo 难以体现系统级创新。本作品 LUT-SA 以开源 T-MAC（EuroSys 2025）LUT 范式为计算引擎，经 NDK 封装后注册为用户态系统能力，对外提供模型加载、推理与指标回传；调度侧联动通知、前台与负载信号，形成「感知→调度→加速」闭环。公开评测显示相对 llama.cpp 反量化基线，边缘 CPU 吞吐可提升约 2.5～5.9 倍（数据见作品说明文档测试报告，非本队板测）。初赛交付架构与技术方案、测试报告雏形及源码包，复赛补齐鸿蒙侧实测与演示闭环，服务端侧隐私推理与低功耗生成场景。

（字数约 320，≤500）
